# Pulse 脉测 · Web 控制台使用指南

Web 控制台是 CLI 的图形界面：同一套协议层，浏览器里完成「配置 → 实时测速 → 汇总/导出/历史」全流程。

## 启动

```bash
pnpm build        # 后端编译
pnpm web:build    # 前端构建（首次必须；产物 web/dist 不入库）
pnpm serve        # 启动：http://localhost:8818
# 或 node dist/cli.js serve --port 8818 --host 0.0.0.0
```

前端开发模式（热更新，代理 API 到 8818）：

```bash
pnpm serve &      # 先起后端
pnpm web:dev      # 打开 http://localhost:5173
```

## 功能

| 区域 | 说明 |
|---|---|
| 模式选择 | Ping / TCPing / HTTP / DNS / Traceroute / 批量 Ping / 批量 TCPing |
| 目标输入 | 单目标输入框；批量模式为多行文本（每行一个，支持 IP/域名/CIDR） |
| 节点选择 | 快捷预设（全部/三网/电信/联通/移动/海外/京沪广深）+ 关键词回车添加；批量模式「逐节点选择」弹窗支持搜索与勾选 |
| 模式选项 | TCPing 端口；HTTP 检测模式/HTTP 版本；DNS 记录类型/自定义 DNS；整体超时 |
| 实时结果 | SSE 帧级推送：帧计数、成功/失败徽标、实时结果流表格 |
| 最终汇总 | 指标卡（平均/最快/最慢/成功率）、分线路平均延迟条形图、最快 TopN、节点明细表（延迟等宽对齐、按延迟排序） |
| 导出 | 表格右上角一键下载 CSV / JSON |
| 历史记录 | 服务端保留最近 50 次，点击回看完整结果；当前结果高亮 |
| 主题 | 右上角深浅色切换，默认跟随系统，选择持久化 |

## 行为说明

- **任务队列**：同一时间只执行一个测速任务（对 itdog 友好），后提交的任务自动排队，界面显示「任务排队中」。
- **批量分片**：所选节点超过 5 个时自动按 5 个一组分片串行，汇总合并展示。
- **超时截断**：到达整体超时未收到完成信号时，结果标记「部分结果」（amber 提示），数据仍然可用。
- **刷新节点**：节点选择区的刷新按钮会重新抓取 itdog 节点表并更新缓存。

## 常见问题

- 页面提示「前端尚未构建」→ 运行 `pnpm web:build`
- 任务一直排队 → 前一个任务未结束（长超时任务会占用队列），可等待或重启 serve
- 创建任务报错 → 参考 [TUTORIAL 故障排查](TUTORIAL.md#9-故障排查-faq)，多为目标格式或节点数超限
