# Velox · 品牌手册

> 版本 2.0 · 适用于 Velox 全系产品（CLI / Web 控制台 / 导出文件）

## 1. 品牌

| | |
|---|---|
| 品牌名 | **Velox**（拉丁语「迅速」） |
| 定位 | IP/CDN 网络优选平台 —— 测速（Inspect）→ 优选（Select）闭环 |
| 产品模块 | Velox Inspect（多节点测速）· Velox Select（IP/CDN 优选） |
| Slogan | Inspect. Select. Accelerate. |
| 中文定位语 | 全网实测 · IP/CDN 网络优选平台 |

**命名故事**：Velox 是拉丁语「迅速」——两个音节，短促有力，首字母 **V** 天然携带速度矢量与折线的视觉联想。品牌叙事建立在产品闭环上：**测速发现问题（Inspect），优选解决问题（Select）**——竞品只给用户一张数据表，Velox 直接给出「用这几个 IP」的答案。

**产品模块命名约定**：`Velox Inspect`（测速）/ `Velox Select`（优选）；文件名前缀 `velox-`。

## 2. Logo

### 2.1 概念

一条**上升折线**穿过**三个节点**：折线是测速曲线（Inspect），三个节点是被检验的 IP（Select）——一个符号讲完整个闭环。折线整体上扬，V 形回撤后强力上升，同时是品牌名 Velox 的首字母。

### 2.2 构造规格

- 画布 128×128，安全边距 4，圆角方砖 `rx=26`
- 折线坐标：`(22,42) (44,90) (76,50) (106,24)`，描边宽 7、圆头圆角
- 三节点：起点 `(22,42)` r=6 `#9AA7B8`（石墨光）；中继点 `(44,90)` r=5 `#00E5C7` 55% 不透明（途经节点）；终点 `(106,24)` r=8 `#00E5C7` + 光晕半径 17
- 折线渐变：`#00E5C7 → #7C9FFF`（自下而上）
- 方砖：`#12161F → #0A0E14` 渐变 + `rgba(255,255,255,0.10)` 1px 描边

### 2.3 变体

| 文件 | 用途 |
|---|---|
| `logo.svg` | 主标志：深色方砖，页头、深色底、分享图 |
| `logo-mono.svg` | 单色版：透明底 + `currentColor`，深浅自适应，正文内联、页脚 |
| `favicon.svg` | 小尺寸简化版（描边加粗 9px、去光晕），浏览器标签 |
| `lockup.svg` | 横排组合（标志 + Velox 字标 + 定位语） |

### 2.4 验收与禁例

- **硬性验收**：缩至 16×16 仍可辨识（favicon 是最高频曝光位）
- ❌ 拉伸/旋转/加投影；❌ 折线改为品牌色以外色系
- ❌ 增删节点数量（三节点 = 探测·路径·回传）
- ✅ 最小可用尺寸：主标志 24px、favicon 16px（用简化版）

## 3. 色彩

### 3.1 基底（70%）——深空近黑，拒绝纯黑

| Token | 深色主题 | 浅色主题 |
|---|---|---|
| 主背景 | `#0A0E14`（hsl 216 33% 6%） | `#F6F8FA` |
| 卡片层 | `#12161F`（提升一层） | `#FFFFFF` |
| 描边 | `rgba(255,255,255,0.08~0.10)` | `#E4E8EE` |

> 暗色界面里 **1px 描边比阴影高级**；阴影只用于浮层（弹窗/下拉）。

### 3.2 强调色（20%）

| Token | 值 | 用途 |
|---|---|---|
| 主色 | `#00E5C7`（电光青） | 品牌色、主按钮、优级、进行中 |
| 浅色主题主色 | `#089C86`（加深保对比） | 浅色底上的 primary |
| 次强调 | `#7C9FFF`（星蓝） | 良级、折线渐变尾 |
| 警示 | `#FFB020`（琥珀） | 中等质量、超时截断提示 |

### 3.3 质量四级（10%）——IP 优选的核心视觉语言

| 等级 | 色值 | 判定 | 语义 |
|---|---|---|---|
| **优** | `#00E5C7` | 延迟 ≤ 50ms 且零丢包 | 放心用 |
| **良** | `#7C9FFF` | ≤ 150ms | 可用 |
| **中** | `#FFB020` | ≤ 300ms 或有抖动 | 观察 |
| **差** | `#FF5C5C` | > 300ms 或丢包 | 换掉 |

> **无障碍硬性规则**：等级不得只靠颜色区分——数值后必须跟随等级字标（优/良/中/差/✕），地图与表格同样适用。约 8% 男性有红绿色觉障碍，而这正是核心用户画像。

## 4. 字体

| 场景 | 字体栈 |
|---|---|
| 数字（最关键） | `JetBrains Mono`（@fontsource 内置）+ `font-variant-numeric: tabular-nums`。测速数字实时跳动，**不等宽整个表格会左右抽搐** |
| 界面西文 | `Inter`（@fontsource 内置），只用 400/500/600 三档字重 |
| 界面中文 | `HarmonyOS Sans SC` → `MiSans` → `PingFang SC` → `Microsoft YaHei` 系统回退（中文 webfont 体积过大，不打包） |

## 5. 界面调性：精密仪器 · 克制 · 数据密度 · 呼吸感

**要做：**
- 圆角统一 8~12px（`--radius: 10px`）
- 表格行高 32~36px，默认紧凑——专业用户讨厌留白浪费
- 动效只做有意义的：数值滚动、进度推进、状态流转（150~300ms，easeOut）
- 加载态与空状态精心设计——测速等待的几十秒是用户情绪最高点
- 结果可导出：一键复制、hosts 导出、CSV/JSON——把「看到数据」变成「做出决策」，也是最自然的传播钩子（带品牌水印的结果图）

**不要做：**
- 满屏渐变光晕、粒子背景、扫光动画（廉价感三件套）
- 每个卡片加彩色图标；用色超过 5 种
- 装饰性弹跳动效；超过 600 的字重

## 6. 语气与文案

- 短句、数据先行：`测试完成：293/295 节点成功`
- 结论先行：测速场景先给判断（成功率/平均/推荐），再给明细
- 错误必带动作：`前端尚未构建，请先运行 pnpm web:build`
- 中英混排时数字与代码一律等宽字体

## 7. 应用示例

- **Web 页头**：`BrandLockup`（标志 34px + Velox 字标 + 定位语），右侧监测点徽标 + 主题切换
- **CLI serve 横幅**：`⚡ Velox —— Web 控制台已启动`
- **导出文件**：文件名 `velox-<mode>-<时间戳>.<ext>`；hosts 导出带 `# Velox` 头注释；JSON 含 `meta.brand = "Velox"`
- **空状态**：mono 版标志 40% 透明度 + 三步引导 + slogan
