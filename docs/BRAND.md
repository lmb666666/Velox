# Pulse 脉测 · 品牌手册

> 版本 1.0 · 适用于 itdog-cli 全系产品（CLI / Web 控制台 / 导出文件）

## 1. 品牌

| | |
|---|---|
| 中文名 | **脉测** |
| 英文名 | **Pulse** |
| 定位 | IP/CDN 网络优选平台 —— 全国监测点测速、Cloudflare/多 CDN 优选 |
| Slogan | 每一次探测，都是脉搏 / Feel the network's pulse |
| 语气关键词 | 数据先行 · 简短专业 · 克制优雅 |

**命名故事**：网络拨测的英文即 "pulse check"（脉搏检查）——每次从监测点发起探测，都是给目标量一次脉搏。Pulse 一词同时涵盖 ICMP Echo、TCP 握手、HTTP 探活与未来的 CDN 优选，短、快、国际化；中文名「脉测」点明「拨测」行业属性。

**文件命名约定**：工具产物统一使用 `pulse-` 前缀（如 `pulse-ping-1725600000.csv`），环境变量使用 `PULSE_` 前缀。

## 2. Logo

### 2.1 概念

一条 ECG 脉冲波形从起点节点出发，贯穿画面，止于带光晕的终点节点 —— 「探测（起点）→ 波动（路径）→ 回应（终点）」。方砖为 App 图标形制，波形线条同时是产品加载动效的母题。

### 2.2 构造规格

- 画布 128×128，安全边距 4，圆角方砖 `rx=30`
- 脉冲折线坐标：`(26,74) (50,74) (60,44) (70,90) (80,58) (90,74) (102,74)`，描边宽 7、圆头圆角
- 起点节点 r=6.5 `#67E8F9`；终点节点 r=8 `#22D3EE`，光晕半径 17（40% 不透明度径向渐变）
- 渐变：脉冲线 `#5EEAD4 → #22D3EE → #38BDF8`；方砖 `#232329 → #0A0A0C`

### 2.3 变体

| 文件 | 用途 |
|---|---|
| `logo.svg` | 主标志：深色方砖，用于页头、深色底、分享图 |
| `logo-mono.svg` | 单色版：透明底 + `currentColor`，深浅主题自适应，用于正文内联、页脚 |
| `favicon.svg` | 小尺寸简化版（描边加粗 9px、去光晕），浏览器标签 |
| `lockup.svg` | 横排组合（标志 + Pulse 脉测字标 + slogan），用于分享/文档封面 |

### 2.4 使用禁例

- ❌ 拉伸/旋转/透视变形；❌ 更换脉冲线颜色为主色以外的品牌色
- ❌ 将方砖圆角改小或直角化；❌ 在方砖上叠加其他文字
- ❌ 在复杂背景上直接使用主标志（应加描边或改用 mono 版）
- ✅ 最小可用尺寸：主标志 24px、favicon 16px（favicon 用简化版）

## 3. 色彩

### 3.1 主色：电光青 Pulse Cyan

| Token | 值 | 用途 |
|---|---|---|
| `pulse-300` | `#67E8F9` | 深色底高亮、起点节点 |
| `pulse-400` | `#22D3EE` | **品牌主色**（深色主题 primary）、终点节点、按钮 |
| `pulse-600` | `#0891B2` | **浅色主题 primary**（对比度达标）、链接 |
| 渐变 | `#5EEAD4 → #22D3EE → #38BDF8` | 品牌字标渐变、进度条、loading |

### 3.2 中性：石墨 Zinc

| 用途 | 深色主题 | 浅色主题 |
|---|---|---|
| 页面底 | `#09090B` (zinc-950) | `#FAFAFA` |
| 卡片/面板 | `#101013` | `#FFFFFF` |
| 边框 | `#27272A` (zinc-800) | `#E4E4E7` (zinc-200) |
| 正文 | `#FAFAFA` | `#18181B` |
| 次要文字 | `#A1A1AA` (zinc-400) | `#71717A` (zinc-500) |

### 3.3 语义色

| 语义 | 值 | 用途 |
|---|---|---|
| 成功 | `#34D399` | 成功节点、连通正常 |
| 失败 | `#F87171` | 丢包/连接失败/错误 |
| 警示 | `#FBBF24` | 超时截断、部分结果 |
| 信息 | `#60A5FA` | 进行中、提示 |

## 4. 字体

| 场景 | 字体栈 |
|---|---|
| 界面正文 | `-apple-system, Segoe UI, PingFang SC, Hiragino Sans GB, Microsoft YaHei, sans-serif` |
| 数据数字/延迟/IP | `JetBrains Mono, ui-monospace, SFMono-Regular, Cascadia Code, Consolas, monospace` + `tabular-nums` |

规则：所有数值（延迟、计数、百分比）必须等宽对齐；中文不使用斜体；正文最小 12px。

## 5. 动效

| 原则 | 规格 |
|---|---|
| 时长 | 微交互 120~200ms；进出场 200~300ms；超过 400ms 视为过度设计 |
| 缓动 | 进场 `easeOut`，离场 `easeIn`；列表行 stagger ≤ 8ms/行 |
| 品牌动效 | 波形 Logo 即加载态：`stroke-dasharray` 流动 + 终点节点呼吸 |
| 数据更新 | 表格行淡入上移（y: 4→0）；指标卡数字不跳变（等宽字体） |
| 禁例 | 不做弹跳、旋转、发光溢出；同一屏同时进行的动效 ≤ 3 组 |

## 6. 语气与文案

- **短句、数据先行**：`测试完成：293/295 节点成功` 优于 `恭喜！您的测试已经全部顺利完成了`
- **错误必须给动作**：`前端尚未构建，请先运行 pnpm web:build`
- **状态三态**：排队中 → 进行中（显示帧计数）→ 已完成/失败（显示汇总）
- 代码/ID/路径一律等宽字体呈现；不使用感叹号堆叠与夸张形容词

## 7. 应用示例

- **Web 页头**：`BrandLockup`（标志 34px + “Pulse 脉测” + 副标 “IP/CDN 网络优选平台”），右侧监测点徽标 + 主题切换
- **CLI serve 横幅**：`⚡ Pulse 脉测 —— Web 控制台已启动` + 地址
- **导出文件**：文件名 `pulse-<mode>-<时间戳>.csv/json`；JSON 顶层含 `meta.brand`
- **空状态**：mono 版标志 50% 透明度 + 一句引导文案 + slogan 小字
