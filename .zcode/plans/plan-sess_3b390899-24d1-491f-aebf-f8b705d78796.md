## 2. Web 端架构（不变）

```
浏览器 SPA (React 18 + Vite + Tailwind + shadcn/ui + framer-motion)
   │ REST + SSE 帧级实时推送
后端 src/web/server.ts（node:http 零框架）
   │ 串行任务队列 + 历史持久化 ~/.cache/itdog-cli/web-history/
协议层 src/service.ts（新增 runTest 共用服务，CLI/Web 复用）
   └── 现有 client/ws/modes/nodes/aggregate 不动
```

- 组件体系：shadcn/ui 官方 copy-paste 模式，源码内联 `web/src/components/ui/`（button/card/input/label/badge/tabs/table/progress/select/dialog/separator/skeleton/sonner），lucide-react 图标
- 深浅色切换：class 策略 + localStorage，默认跟随系统，无闪屏；响应式布局
- 动效：framer-motion —— 卡片级联淡入、数据行滑入、波形 Logo 加载态、数字滚动

## 6. 风险与对策

- shadcn CLI 交互式 → 官方 copy-paste 模式手工内联组件源码（等效可自持）
- 前端产物不入库 → serve 检测 web/dist 缺失提示「先 pnpm web:build」
- 并发风控 → 服务端串行队列 + 分片间歇，Web 端排队状态可视化
